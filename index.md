## Flow

1. **Capture** → note baru mendarat di `00-inbox/` (dari HP/agent, bebas format)
2. **Organize** → weekly sweep: pindah ke `10-concepts/` (atomic), `20-areas/`, `30-projects/`, atau `50-resources/`
3. **Distill** → tambah link antar note, buat MOC kalau topik rame
4. **Express** → pakai pengetahuan ini buat kerjaan beneran

## Rules

- English only.
- One note = one idea (`10-concepts/`).
- Frontmatter minimal: `type`, `title`, `tags`, `date`/`created`.
- Link, jangan cuma tag — `[[wikilink]]` = relasi, folder = lokasi.
- New knowledge = new file. Jangan rewrite note lama.
- Pindah ke `40-archive/` kalau project kelar / topik mati. Jangan hapus.
